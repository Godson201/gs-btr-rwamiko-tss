# G.S BTR RWAMIKO TSS - Official Website & School Management System

## Overview
A modern, secure, and responsive website integrated with a comprehensive School Management System (SMS) for G.S BTR RWAMIKO TSS.

## School Information
- **Location**: Ruramba Sector, Nyaruguru District, Western Province, Rwanda
- **Motto**: "Through Here, Wealth is Flash"
- **Vision**: Excellent Education System
- **Mission**: Innovative school management, smart school of productivity, efficiency, training

## Technology Stack
- Frontend: Next.js, React, Tailwind CSS, shadcn/ui
- Backend: Node.js, NestJS, TypeScript
- Database: PostgreSQL, Prisma ORM
- Security: JWT, RBAC, Password Encryption
- Deployment: Docker, Nginx, HTTPS

## Features
- Public Website with full school information
- School Management System with role-based access
- Student, Teacher, Parent, and Admin Portals
- Academic Management (classes, subjects, exams, results)
- Communication and Notification System
- Responsive and accessible design
